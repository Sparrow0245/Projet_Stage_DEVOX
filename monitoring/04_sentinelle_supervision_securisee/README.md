# Sentinelle V4 – Supervision Sécurisée

## Présentation

Sentinelle V4 est une plateforme de supervision système et de cybersécurité destinée aux serveurs Ubuntu.

Elle permet :

- la supervision système en temps réel ;
- le suivi des événements de sécurité ;
- la collecte de métriques système ;
- l'authentification sécurisée avec JWT et TOTP ;
- l'authentification des administrateurs Linux via PAM ;
- la gestion des utilisateurs ;
- la journalisation dans MySQL, journalctl et des fichiers logs ;
- le déploiement automatisé.

---

## Modules

- Backend Spring Boot 3
- Frontend Vue.js
- Base MySQL
- Apache
- PHP
- Scripts Bash
- Services systemd
